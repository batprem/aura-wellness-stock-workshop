# Prompting for this product

Habits from the Module 5 session:

1. **One feature per prompt.**
2. **Say which part:** frontend, backend, or database.
3. **Say what “done” looks like.**
4. **Ask for the plan first, then the code.**
5. **Say what not to add.**

Put rules that apply to every prompt — the three-feature scope and, once agreed, the \[threshold\] — into `CLAUDE.md` so you do not have to repeat them.

## Example prompt — not a required script

This is a sample only. Adapt it to your own app.

> Add Feature 2 to the stock app. Backend: an API that returns the stock table from the database. Frontend: a page that shows it as a table, only after login. Done = I can log in and see every item with its quantity. Do not add editing or any other feature. Show me your plan before you write code.
