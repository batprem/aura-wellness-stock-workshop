# Example dashboard data — not real Aura data

[`example-dashboard.csv`](example-dashboard.csv) is invented for the Module 2 warm-up. It is not Aura data.

It is one small table: example weekly unit counts for a few items, across several weeks, with a category on each row. That is enough for a one-page dashboard with a few views (for example totals by week, by item, or by category). You may replace it with other example rows — still not real Aura records.

Use this file wherever the slides say `[sample data file]`.

## example-transactions.csv

[`example-transactions.csv`](example-transactions.csv) is example data for the Module 2 personal finance workshop: about three months of made-up transactions (65 rows, 8 categories) with columns `date`, `description`, `category`, `amount`, `type` (`in` or `out`). It includes a monthly salary, a few repeating bills and one unusually large expense.
