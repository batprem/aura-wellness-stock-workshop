# Module 2 workshop — prompts, in order

Send one at a time and check the result before the next. Adapt the wording.

## 1. Describe the data

> Look at `example-transactions.csv`. Tell me its columns, how many rows and months it covers, and which categories it has. Don't write any code yet.

## 2. Plan

> I want a one-page personal finance report from this file. It should open in the browser from this folder, with no server, no login and no database. Propose a plan for the page and the files you would create. Show me the plan before you build.

## 3. Totals

> Build the page with the four summary cards only: money in, money out, what's left, and savings rate, for the latest month in the file. Tell me how I can check one of the numbers by hand.

## 4. Chart and table

> Add a spending-by-category chart, a month-by-month chart of money in vs out, the top 5 biggest expenses, and a transactions table I can sort and search. Keep the page simple.

## 5. Month picker

> Add a month picker. When I pick a month, the cards, the category chart, the top 5 and the table should all update.

## 6. One change of your own

> Make one small change only: [pick one — budgets with an over-limit warning / change vs last month / recurring payments / upload my own CSV with the same columns / print or save as PDF]. Tell me what you will change before you do it.
